About

The benchmark

602 papers that introduce ML datasets. 102 have human-validated gold annotations (3,060 cells from 22 annotators), split into 14 development and 88 test papers; 500 have LLM-generated silver annotations. Systems receive the PDF and return the 10 core and 20 Responsible AI fields of Croissant 1.1.

Designs

Single-pass: one model call over the full paper with the canonical prompt. ReAct: a tool-using agent loop. Parallel Specialists: five specialists, one per field group. Triage + Critique: triage, one extraction with quotes, and a review of missing fields. Locator-Extractor: a locator picks passages, extractors read only those.

Scoring

Core averages the 10 core fields, scored by rules. RAI averages the 20 Responsible AI fields, scored by a judge model against the gold answer. Composite weights all 30 fields equally. The 95% confidence intervals come from 2,000 bootstrap samples over papers.

Claude-based systems

Claude Sonnet 4.5 drafted the gold annotations before annotators checked them, so it is shown for reference and not ranked, and systems built on Claude models are marked with *.

Add your system

  1. Download the papers and run your system on the 88 test papers, one JSON file per paper with the 30 fields. Tune on the 14 development papers only; the test gold annotations are public, so do not train on them.
  2. Score it with make evaluate OUTPUTS=outputs NAME=my-system. The Responsible AI answers go to the same judge as every row here (about US$0.75 per system).
  3. Open a pull request with the folder the script writes and a row in leaderboard/leaderboard.csv. This page updates when the pull request is merged.

Full steps, file format and rules: leaderboard/README.md.
