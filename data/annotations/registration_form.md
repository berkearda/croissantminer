## Section 1 of 4: CroissantMiner Annotation Study - Register Your Interest

We are recruiting annotators for a human evaluation study as part of ongoing research on automated metadata
extraction for ML datasets.

ABOUT THE PROJECT
CroissantMiner is an automated framework that uses Large Language Models to extract structured metadata from ML
dataset papers, following the MLCommons Croissant schema. This work builds on the Croissant metadata format (Akhtar et
al., NeurIPS 2024 Spotlight) and aims to establish scalable, responsible dataset documentation workflows.

WHAT WILL YOU DO?
You will review metadata fields automatically extracted by an LLM from academic papers describing ML datasets. For
each field, you will:
- Judge whether the extracted value is correct (TRUE/FALSE)
- Provide a correction if incorrect
- Rate your confidence in the judgement

Each annotator will be assigned a small set of specific metadata fields and will review those fields across multiple
dataset papers. You will receive a formatted spreadsheet with clear instructions and the extracted values pre-filled
for your review.
